# json

> Free online JSON formatter, viewer and differ. Paste or drop JSON and see it formatted instantly — multi-MB documents render in milliseconds. Runs 100% in your browser: no uploads, no cookies, no tracking.

## Use it

Open [https://json.justgiulio.dev/](https://json.justgiulio.dev/) and paste JSON anywhere on the page (⌘V / Ctrl+V), or drop a `.json` file.

## What you get

- Pretty-print with 2-space, 4-space or tab indent
- Collapsible tree view
- Minified output, one click copy
- Diff two JSON documents (changes view + side by side)
- Find with plain text or regular expressions (⌘F / Ctrl+F)
- JSONL support (one JSON document per line)
- Works offline after first load; nothing ever leaves your browser

## When to use this tool

- You need to read, format or inspect JSON of any size (tested into the multi-MB range) right now, with zero setup
- The JSON is sensitive (tokens, PII, customer data) and must not be uploaded anywhere — processing is 100% client-side
- You need to compare two JSON documents and see exactly which keys/values changed
- You need minified or pretty-printed output to copy back into your code

Not a fit for: scheduled/automated conversions (it is an interactive tool, not an API) or editing JSON with schema validation.
