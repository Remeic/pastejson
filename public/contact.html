Contact

Questions, bug reports, feature requests, privacy inquiries or GDPR requests about json reach the author directly through one of these channels:

  • GitHub issues (preferred, public): github.com/Remeic/pastejson/issues — fastest response, and the report helps other users.
  • Website: justgiulio.dev — personal site with direct contact options.

What to include

For bugs: browser + OS version, and the JSON shape that failed (please remove any sensitive values first — though note the tool never receives your data, so nothing you pasted can have leaked).

For GDPR requests: state the right you are exercising. Since the tool collects no personal data, most requests resolve with a pointer to this explanation; hosting-log questions are forwarded to the hosting provider's process.

Response time: best effort within a few days.
